# Design proposals

These documents preserve reviewed designs, implementation plans, and their
review histories. They are non-normative unless an active document explicitly
adopts part of them. Current user, wire, extension, and control contracts remain
in the top level of `docs/`.

- `selectable-control-and-pll.md`: the reviewed cross-repository design that
  produced `StandardControl`, the revised `StandardProgram` and `Pll`, and the
  magneto-elastic rig's selectable control policy.
- `rig_decoupling_proposal.md`: the completed component-ownership and
  out-of-tree rig design.
- `rt_program_proposal.md`: the completed real-time programme ownership design,
  retained where it is not superseded by rig decoupling.
- `hawk-rig.md`: an unimplemented hardware and firmware plan.
